# 🧠 ML Learning Lab

> Learning Machine Learning by building, experimenting, failing, debugging, and understanding.

## 🎯 About

This repository documents my hands-on journey of learning Machine Learning.

I don't want to learn ML by simply completing tutorials. My approach is:

**Learn → Implement → Experiment → Fail → Debug → Understand → Document → Repeat**

This repository contains my implementations, experiments, notes, datasets, and lessons learned throughout the journey.
